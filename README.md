# EmberClaw 🦊

> 24/7 IoT 系统开发 CLI 编程 Agent

**EmberClaw** 是一个完全私有、可长期迭代的 CLI 编程 Agent，专注于 IoT 系统全栈开发。

## 核心能力

- 📡 **Nordic nRF 固件 + nRF Mesh 开发**
- ⚡ **开关电源控制驱动**
- 🍓 **树莓派 Linux 网关部署与调试**
- 📱 **iOS / Android App 开发**
- 🌐 **Web 全栈开发**
- 🔄 **端到端集成测试与部署**

## 技术栈

- **主框架**: OpenClaw
- **编程引擎**: claw-code (Rust)
- **语言**: TypeScript + Rust
- **工具层**: Serial MCP / SSH MCP / Docker MCP

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/your-username/emberclaw.git
cd emberclaw

# 安装依赖
npm install

# 配置 API Key
export ANTHROPIC_API_KEY="your-key"

# 启动
npm run dev
```
